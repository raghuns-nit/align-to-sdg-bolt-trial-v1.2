# UI Inspiration References

These sites are **design/interaction references only**. Do not copy branding, proprietary artwork, exact layouts, or product identity.

## 1. Apple
Primary reference: https://www.apple.com/  
Design resources: https://developer.apple.com/design/resources/

Use for: whitespace, restrained hierarchy, typography discipline, limited primary actions, calm content-first visual structure.

## 2. Brilliant
Primary reference: https://brilliant.org/

Use for: guided step-by-step interaction, progressive disclosure, approachable cards, clear next actions, learn-by-doing interaction patterns.

## 3. Our World in Data — ETL computational graph / DAG
Computational graph: https://docs.owid.io/projects/etl/architecture/design/compute-graph/  
DAG: https://docs.owid.io/projects/etl/architecture/design/dag/

Use for: inspectable dependency/graph structure, directional relationships, transparent technical provenance, graph-as-explanation.

## 4. arcmodel.io — Knowledge Graph Instances reference
Prior project reference: https://arcmodel.io/

Use for: graph-canvas-first interaction, readable node/edge semantics, instance exploration, node inspection, path/focus patterns. This reference was supplied/used earlier in the project; if the site is unavailable, rely on the included approved KG wireframes and current UI specification.

## Governing rule
The approved `UI_Design_v0.3.docx` and its companion decision/binding/help repositories override any stylistic inference from these references.
